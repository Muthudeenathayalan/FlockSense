# Cloud Firestore Data Architecture & Security Rules

This document outlines the Firestore document paths, indexing policies, serialization standards, and security scoping rules for FlockSense.

---

## 1. Document Path Hierarchy

All farm records, batches, telemetry, inventory, finance, notifications, and settings are strictly scoped under the authenticated user's UID (`users/{uid}`):

### User Root
- **Path**: `users/{uid}`
- **Purpose**: User profile, global preferences, and farm pointers.
- **Fields**: `uid` (string), `name` (string), `email` (string), `phone` (string), `role` (string), `hasCompletedOnboarding` (bool), `hasFarm` (bool), `activeFarmId` (string?), `fcmToken` (string?), `createdAt` (timestamp/string), `updatedAt` (timestamp/string)

---

### Farm Level (Subcollection under User)
- **Path**: `users/{uid}/farms/{farmId}`
- **Purpose**: Farm physical infrastructure, location, dimensions, and bird capacity.
- **Fields**: `id`, `userId`, `ownerId`, `farmName`, `farmerName`, `farmType`, `flockType`, `address`, `lengthFt` (double), `widthFt` (double), `totalSqFt` (double), `sizeUnit`, `capacity` (int), `district`, `state`, `country`, `phoneNumber`, `notes`, `isLocationAuto` (bool), `status`, `createdAt`, `updatedAt`

#### 1. Sheds
- **Path**: `users/{uid}/farms/{farmId}/sheds/{shedId}`
- **Fields**: `id`, `farmId`, `userId`, `ownerId`, `shedName`, `lengthFt`, `widthFt`, `totalSqFt`, `capacity`, `status`, `notes`, `createdAt`, `updatedAt`

#### 2. Farm Inventory Items
- **Path**: `users/{uid}/farms/{farmId}/inventoryItems/{itemId}`
- **Fields**: `id`, `farmId`, `ownerId`, `itemName`, `category` (Feed, Medicine, Vaccine, Equipment, Litter, Other), `quantityAvailable` (double), `unit`, `minStockLevel` (double), `costPerUnit` (double), `purchaseDate`, `supplier`, `batchNumber`, `expiryDate`, `storageLocation`, `notes`, `createdAt`, `updatedAt`

##### Stock Movements (Subcollection under Item)
- **Path**: `users/{uid}/farms/{farmId}/inventoryItems/{itemId}/stockMovements/{movementId}`
- **Fields**: `id`, `inventoryItemId`, `farmId`, `ownerId`, `action` (increase, decrease, adjustment), `quantity` (double), `reason`, `date`, `supplier`, `userName`, `notes`, `createdAt`

#### 3. Calendar Events
- **Path**: `users/{uid}/farms/{farmId}/calendarEvents/{eventId}`
- **Fields**: `id`, `farmId`, `batchId`, `ownerId`, `title`, `eventType`, `description`, `eventDate`, `eventTime`, `repeat`, `priority`, `reminderBeforeMinutes`, `isCompleted`, `completedAt`, `isAutoGenerated`, `autoSource`, `notes`, `createdAt`, `updatedAt`

---

### Batch Level (Subcollection under Farm)
- **Path**: `users/{uid}/farms/{farmId}/batches/{batchId}`
- **Purpose**: Active or harvested flock batch lifecycle.
- **Fields**: `id`, `farmId`, `shedId`, `ownerId`, `batchName`, `lengthFt`, `widthFt`, `areaSqFt`, `sizeUnit`, `hatchDate`, `placementDate`, `maleCount` (int), `femaleCount` (int), `totalBirds` (int), `currentBirds` (int), `breedOrFlockType`, `chickAvgWeight` (double?), `hatcheryName`, `supervisorName`, `vehicleNumber`, `status` ('active', 'completed', 'sold'), `notes`, `createdAt`, `updatedAt`

#### 1. Daily Records
- **Path**: `users/{uid}/farms/{farmId}/batches/{batchId}/dailyRecords/{recordId}`
- **Key Convention**: `recordId = yyyy-MM-dd` (deterministic per day)
- **Fields**: `id`, `farmId`, `batchId`, `recordDate`, `batchAgeDay` (int), `openingBirds` (int), `mortalityCount` (int), `cullCount` (int), `adjustmentCount` (int), `closingBirds` (int), `feedConsumedKg` (double), `waterConsumedLiters` (double), `avgWeightGrams` (double), `feedType`, `feedBatchNumber`, `feedBags`, `waterSource`, `waterQuality`, `mortalityCause`, `sampleBirds`, `medicineGiven` (bool), `medicineDose`, `vaccineGiven` (bool), `vaccineDose`, `temperature` (double), `humidity` (double), `weather`, `dgLevelLiters` (double), `dgAddedLiters` (double), `dgRunningHours` (double), `dgName`, `notes`, `createdAt`, `updatedAt`

#### 2. Bird Sales Records
- **Path**: `users/{uid}/farms/{farmId}/batches/{batchId}/salesRecords/{saleId}`
- **Fields**: `id`, `farmId`, `batchId`, `date`, `birdCount` (int), `totalWeightKg` (double), `averageWeightKg` (double), `pricePerKg` (double), `totalRevenue` (double), `buyerName`, `vehicleNumber`, `paymentMethod`, `paymentStatus`, `notes`, `createdAt`

#### 3. Feed Transactions
- **Path**: `users/{uid}/farms/{farmId}/batches/{batchId}/feedTransactions/{txId}`
- **Fields**: `id`, `farmId`, `batchId`, `transactionDate`, `transactionType` (purchase, consumption, transfer), `feedType`, `feedBatchNumber`, `dcNumber`, `bags` (int), `weightPerBagKg` (double), `totalKg` (double), `supplierOrSource`, `destination`, `costPerKg` (double), `totalCost` (double), `notes`, `createdAt`

#### 4. Weight Records
- **Path**: `users/{uid}/farms/{farmId}/batches/{batchId}/weightRecords/{recordId}`
- **Key Convention**: `recordId = yyyy-MM-dd`
- **Fields**: `id`, `farmId`, `batchId`, `recordDate`, `averageWeight` (double), `unit`, `sampleCount` (int), `notes`, `createdAt`, `updatedAt`

#### 5. Vaccine Records
- **Path**: `users/{uid}/farms/{farmId}/batches/{batchId}/vaccineRecords/{recId}`
- **Fields**: `id`, `farmId`, `batchId`, `date`, `vaccineName`, `route`, `batchNumber`, `administeredBy`, `cost` (double), `notes`, `createdAt`

#### 6. Medicine Records
- **Path**: `users/{uid}/farms/{farmId}/batches/{batchId}/medicineRecords/{recId}`
- **Fields**: `id`, `farmId`, `batchId`, `date`, `medicineName`, `dosage`, `durationDays` (int), `administeredBy`, `cost` (double), `notes`, `createdAt`

### User-Scoped Global Collections

#### 1. Finance Transactions
- **Path**: `users/{uid}/finance_transactions/{txId}`
- **Fields**: `id`, `ownerId`, `title`, `description`, `amount` (double), `type` ('income' | 'expense'), `category`, `paymentMethod`, `paymentStatus` ('paid', 'pending', 'overdue'), `date`, `invoiceNumber`, `counterparty`, `relatedFarmId`, `relatedBatchId`, `receiptUrl`, `createdAt`

#### 2. Finance Budgets
- **Path**: `users/{uid}/finance_budgets/{budgetId}`

#### 3. Notifications
- **Path**: `users/{uid}/notifications/{notificationId}`
- **Deterministic Key Conventions**:

- **Fields**: `id`, `title`, `body`, `type`, `priority`, `status` ('unread', 'read', 'pinned', 'archived'), `createdAt`, `relatedFarmId`, `relatedBatchId`, `actionUrl`, `isSmartAlert` (bool), `isAiAlert` (bool), `metadata` (map)

#### 4. Reminders
- **Path**: `users/{uid}/reminders/{reminderId}`
- **Fields**: `id`, `title`, `description`, `date`, `time`, `repeat` ('none', 'daily', 'weekly', 'monthly'), `isCompleted` (bool), `completedAt`, `createdAt`

#### 5. Notification Settings
- **Path**: `users/{uid}/notification_settings/general`
- **Fields**: `enablePushNotifications` (bool), `enableDailyReminder` (bool), `enableLowStockAlerts` (bool), `enableHealthAlerts` (bool), `enableFinanceAlerts` (bool), `reminderHour` (int), `reminderMinute` (int), `quietHoursStart` (int), `quietHoursEnd` (int)

#### 6. User Preferences
- **Path**: `users/{uid}/settings/preferences`
- **Fields**: `weightUnit` ('kg' | 'lbs' | 'g'), `currency` ('INR' | 'USD' | 'EUR' | etc.), `dateFormat`, `themeMode`, `updatedAt`

#### 7. AI Conversations
- **Path**: `users/{uid}/ai_conversations/{convId}`
  - Subcollection: `users/{uid}/ai_conversations/{convId}/messages/{msgId}`

#### 8. Audit Logs
- **Path**: `users/{uid}/audit_logs/{logId}`
- **Fields**: `id`, `userId`, `operation`, `operationName`, `resourceType`, `resourceId`, `changes` (map), `success` (bool), `errorMessage`, `timestamp`

## 2. Serialization & Type Resilience Rules

To eliminate runtime type exceptions (`type 'int' is not a subtype of type 'double' in type cast`):
1. **Numeric Parsers**:
   ```dart
   double parseDouble(dynamic v) {
     if (v is double) return v;
     if (v is int) return v.toDouble();
     if (v is String) return double.tryParse(v) ?? 0.0;
     return 0.0;
   }

   int parseInt(dynamic v) {
     if (v is int) return v;
     if (v is double) return v.toInt();
     if (v is String) return int.tryParse(v) ?? 0;
     return 0;
   }
   ```
2. **Date Parsers**:
   Must gracefully parse Firestore `Timestamp`, ISO-8601 `String`, and epoch `int`:
   ```dart
   DateTime parseDate(dynamic v) {
     if (v is Timestamp) return v.toDate();
     if (v is String && v.isNotEmpty) {
       return DateTime.tryParse(v) ?? DateTime.now();
     }
     if (v is int) return DateTime.fromMillisecondsSinceEpoch(v);
     return DateTime.now();
   }
   ```
3. **Safe Firestore Writes**:
   Always prefer `.set(data, SetOptions(merge: true))` over `.update(data)` when documents might not yet exist (e.g. FCM token registration, profile sync).

## 3. Cross-Farm Streaming Architecture (Zero Index Dependency)

Rather than relying on Firestore `collectionGroup` queries which fail when composite indexes are not deployed in Google Cloud Console, FlockSense streams across subcollections by listening to user's farms and merging child listeners:
- `BatchService.watchAllUserBatches`
- `InventoryService.watchInventoryItems`
- `ShedService.watchAllUserSheds`
- `CalendarService.watchCalendarEvents`

**Benefits**:
- Works out-of-the-box on fresh Firebase projects without deploying composite indexes.
- Instant cache response during offline periods.
- Strict compliance with `users/{userId}/{document=**}` isolation.

## 4. Firestore Security Rules Blueprint

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Strict user isolation rule: Users can only read and write their own data
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }

    // Deny all other unauthenticated or cross-tenant access
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```
